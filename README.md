# ແຜນທີ່ສາຂາ Vari

Branch map for the Vari team (Vientiane). The page holds no customer data: it asks for the team PIN and then loads
branches, customer points and branch profiles from the Supabase edge function `branch-profiles` (project vari-trucks).

`index.html` is generated by `build_branch_map.py` in the private Drive folder — do not edit it here.
